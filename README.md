# backend_casop
Backend de aplicacion

En esta parte del backend esta la logica de funcionamiento de nuestra aplicacion,
aplicando buenas tecnicas de programacion, en el cual si se quiere levantar en ambiente local 
unicamente hay que cambiar la linea de DefaultConnection de nuestro archivo appsettings.json

Actualmente esta apuntando a una instancia de Sql server 2022 en mi maquina.

Adjunto tambien el script de la base de datos que contiene la creacion de la tabla, procedimientos almacenados
y los inserts de los datos de prueba que se agregaron, este archivo se llama db_prueba_prom.sql,
que esta en la raiz del proyecto, solo hay que ejecutarlo para levantar la estructura de la base de datos.
